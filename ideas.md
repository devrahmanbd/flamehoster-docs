# Brick Documentation Website Design (ideas.md)

## Three Stylistic Approaches

1. **Theme Name: OpenDevin / OpenHands Style**
   - **Very Brief Intro**: Clean, developer-centric documentation with a high-contrast dark sidebar, sleek typography, interactive code tabs, and a modern technical aesthetic.
   - **Probability**: 0.03

2. **Theme Name: Omnivore Minimalist Paper**
   - **Very Brief Intro**: Warm, editorial paper-like aesthetic with crisp typography, subtle amber/slate accents, and distraction-free reading experience.
   - **Probability**: 0.02

3. **Theme Name: Vercel / Linear Enterprise**
   - **Very Brief Intro**: Ultra-refined dark mode aesthetic with glowing gradient borders, mono badges, pill-shaped tabs, and gorgeous smooth motion.
   - **Probability**: 0.04

---

## Selected Approach: OpenHands / Vercel Hybrid Enterprise Documentation

- **Design Movement**: Modern Developer Documentation (OpenHands / Linear / Vercel style)
- **Core Principles**:
  1. **Instant Clarity**: Hierarchical sidebar with collapsible category groups, live search box, and quick-jump keyboard shortcuts (`Cmd+K`).
  2. **Immersive Code & Architecture**: Syntax-highlighted code blocks with copy buttons, interactive tabs, and embedded Mermaid-style system architecture diagrams.
  3. **Visual Depth**: Subtle background glows, glassmorphism headers (`backdrop-blur-md`), and crisp monospace badges for technical tags (e.g. `v2.5-stable`, `SATURE`, `NFTables`).
  4. **Enterprise Authority**: Meticulous documentation covering the SATURE transactional update engine, out-of-band sentinel watchdog, 5-pillar security stack, and 126+ app marketplace deployment guides.
- **Color Philosophy**: Deep obsidian/slate background (`oklch(0.13 0.005 285)`) paired with vibrant electric blue and cyan accents (`oklch(0.6 0.2 250)`) for code highlights and active states, creating a focused, high-end developer environment.
- **Layout Paradigm**: 3-column documentation layout (Sticky Left Sidebar Navigation, Center Main Markdown Reader, Right-side Page Table of Contents).
- **Signature Elements**: Glowing callout boxes, interactive terminal widget simulations, status badges for system pillars, and copyable CLI command panels.
- **Interaction Philosophy**: Instant tab switching, keyboard navigation support, smooth scroll anchoring, and copy-to-clipboard feedback animations.
- **Animation**: 150ms ease-out transitions on sidebar expansions, tab changes, and modal dialogs.
- **Typography System**: 
  - Sans-serif: `Inter` or `Plus Jakarta Sans` for clean headings and body text.
  - Monospace: `JetBrains Mono` or `Fira Code` for all code snippets, CLI instructions, and configuration files.
- **Brand Essence**: Mission-critical enterprise hosting panel documentation — uncompromisingly reliable, secure, and developer-friendly.
- **Brand Voice**: Precise, authoritative, and developer-oriented.
  - Example 1: "Deploy Brick in 60 seconds with bulletproof transactional rollbacks."
  - Example 2: "SATURE guarantees zero-downtime kernel and system state recovery."
- **Wordmark & Logo**: A clean geometric stacked brick icon in vibrant cyan/blue with "Brick Docs".
- **Signature Brand Color**: Electric Cyan (`#06b6d4` / `oklch(0.7 0.18 215)`).
